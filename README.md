# A Shepherd's Debt

## Overview
A 2D top-down psychological action/horror game created for Brackeys Game Jam 2026.2.

* **Developer:** TechnoVulcan
* **Engine:** Unity (2D Universal Render Pipeline)
* **Playable Build:** [Play on itch.io](https://technovulcan.itch.io/)

## Key Technical Features
* **Custom Mechanics:** Custom C# dialogue state machines, tilemaps, and 2D player movement vector handling.
* **Lighting & Vision:** Custom URP 2D light sources paired with procedural darkness masks for atmospheric exploration.
* **Original Assets:** Built entirely without AI tools—featuring custom pixel art, original level design, and handcrafted sprite animations.

## Story & Setting
Explore the dark, haunting atmosphere of *Dämmerhafen* as you unravel the mystery behind *A Shepherd's Debt*.
